# 🍔 QuickBite – Full Stack Food Delivery Application

QuickBite is a modern full-stack food delivery platform designed to simulate a real-world food ordering experience. The application allows users to explore restaurants, browse menus, place orders, purchase memberships, and interact with an AI-powered chatbot assistant.

Built with a scalable architecture using React.js, Node.js, Express.js, Prisma ORM, and PostgreSQL, QuickBite focuses on performance, security, real-time updates, and seamless user experience.
